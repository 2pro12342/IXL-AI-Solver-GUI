## What is an AI API Key and how do i get it? 
- An AI API key tells you the info about the AI (which AI it is), the AI model, the AI permission, the AI access, and more. the key is used to control chats and permission access so projects, urls, or other AI's can connect and communicate.
  
1. go to your AI site.
2. log in or sign up with an account.
3. either find it in settings or ask the ai the generate you the AI's API key.
4. paste the API key into the IXL GUI Script.
  
## how do I use the GUI? 
- Either use DevTools Console and paste code or use TamperMonkey Extension to install userscripts.

### What if both of those are blocked? 
- Use an unblocker/proxy and use their DevTools feature if they have one, then go into the DevTools Console & paste the code.
